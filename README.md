# Yasmin Shaik Portfolio

A modern personal portfolio website for **Yasmin Shaik**, showcasing frontend development skills, projects, experience, and contact details.

## Features

- Responsive design with modern UI
- Dark mode toggle with localStorage support
- Smooth scrolling navigation
- Animated skill progress bars and counters
- Project cards with GitHub links
- Contact form with validation
- Resume download button
- Profile photo section

## Pages / Sections

- **Home** - Introduction and primary call-to-action buttons
- **About** - Personal summary and education
- **Experience** - Internship and academic experience timeline
- **Skills** - Skill levels and animated counters
- **Projects** - Showcase of GitHub projects
- **Contact** - Email, phone, LinkedIn, GitHub, and contact form

## Project Files

- `index.html` — main portfolio page
- `styles.css` — custom styling for the site
- `script.js` — interactive features and animations
- `yasmin.png` — profile image used on the homepage
- `Yasmin_resume.pdf` — downloadable resume file

## Usage

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Use a local server for best results (recommended).

## Run Locally

If you want to serve the site locally, use a simple Python server from the project directory:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Customization

- Replace `yasmin.png` with your own profile photo.
- Update `Yasmin_resume.pdf` with your latest resume.
- Edit `index.html` to add new projects or change details.
- Update `styles.css` to adjust colors, spacing, or layout.
